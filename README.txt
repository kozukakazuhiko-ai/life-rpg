人生はRPG PWA v0.1

公開方法（GitHub Pages）:
1. GitHubに新しいPublicリポジトリを作成（アプリのコードは公開されます。個人の記録JSONはアップロードしないでください）。
2. このZIPを解凍し、life-rpg-pwaフォルダの中身をリポジトリのルートへアップロード。
3. Settings > Pages > Build and deployment > Deploy from a branch > main / (root) > Save。
4. 発行されたHTTPS URLをAndroid Chromeで開く。メニューから「ホーム画面に追加」または「アプリをインストール」。
5. 旧HTMLのHelpからJSONバックアップを保存し、新URLのHelpからJSONを復元。

注意: URLを知っている人がアプリ本体を開けます。記録は各ブラウザのlocalStorageに保存され、端末間同期されません。GitHubへバックアップJSONをアップロードしないでください。Chromeのサイトデータを消すと記録が消える場合があります。
